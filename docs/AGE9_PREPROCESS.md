## Visual-plan preprocessing

All Age 9 poems have been upgraded to:

~~~text
visual_plan_version = visual_plan_v2
semantic_mode       = source_grounded_scene_v2
visual_plan_status  = draft
~~~

The draft status is deliberate. Age 9 contains substantially more long poems,
warfare, death, alcohol, palace/adult relationship material, supernatural
imagery, and historical allusions than the younger cohorts.

The source-grounded plan is deterministic and does not invent entities. A
semantic safety review must add specific Scene notes where needed before the
plans may be promoted to `approved`.

Blank separator Scenes remain in each plan with no added semantic content.

## Next gates

1. Age 9 structural gate.
2. Project-font coverage and compatibility/synthesized glyph fixes.
3. Pronunciation-sensitive inventory for title / author / poem text.
4. Classify `character + reading` rules using the shared
   `data/tts_pronunciation_proxy_registry.json`.
5. Add only genuinely new proxy rules; validate each new proxy once on one
   representative audio asset.
6. Review Age 9 source-grounded visual plans for sensitive/ambiguous Scenes and
   promote the cohort to `approved`.
7. Only then start full TTS / image production.

Canonical title, author, content, child explanations, and physical-line Scene
boundaries are immutable throughout preprocessing.
